# 🚀 Web開発サンドボックスへようこそ！

この環境では、Python を使った Web アプリの作成や、Linux のコマンド操作を学ぶことができます。
このファイルは最初から用意されている説明ファイルです。読み終わったら自由に編集・削除してかまいません。

## 💡 基本的な使い方

1. 左側の📁アイコンからファイルツリーを開き、ファイルをクリックすると中央のエディタで開けます。
2. 下部のターミナルで `python3 ファイル名.py` のようにコマンドを入力して実行します。
3. コード補完やエラー表示(赤波線)はPython標準で有効になっています。
4. エラーが出た場合は、エディタやターミナルに表示されるメッセージを参考に修正してみましょう。

## 📝 変更の保存(コミット)

右上の「保存(コミット)」ボタンを押すと、今の状態にメッセージを付けて保存できます。
あとから「変更履歴」で見返すことができるので、こまめに保存しておくと安心です。

## 🔗 GitHubへの公開(任意)

この環境に「GitHub連携」機能はありません。「保存(コミット)」や「変更履歴」タブで貯まっていく履歴は、あくまでこのサンドボックス専用のローカルなgit履歴です。GitHubへ公開したい場合は、下部のターミナルから通常のgitコマンドで手動で行ってください。

1. GitHub側で公開先のリポジトリを(空の状態で)作成する
2. ターミナルで以下を実行する:
   ```
   git remote add origin https://github.com/ユーザー名/リポジトリ名.git
   git push -u origin main
   ```
3. パスワードを聞かれたら、GitHubのパスワードではなく **Personal Access Token** を入力してください(GitHubは通常のパスワードでのpushを廃止しています)。トークンはGitHub右上のアイコン→Settings→Developer settings→Personal access tokensから発行できます。

一度 `git remote add` しておけば、2回目以降は `git push` だけで反映できます。

## 🐍 使えるもの

- Python 3(pip・venv 対応)
- Flask / Flask-SQLAlchemy / requests / python-dotenv(あらかじめインストール済み)
- git(この環境専用の履歴管理。GitHubへの公開方法は上記「🔗 GitHubへの公開」を参照)

## ⌨️ ターミナルのコピー&ペースト

文字を選択した状態で `Ctrl+C` でコピー、`Ctrl+V` でペーストできます。日本語の入力・表示にも対応しています。
